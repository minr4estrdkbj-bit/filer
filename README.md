# Filer - ブラウザで動くキーボード駆動型ファイルマネージャー

ブラウザ上で動作する高機能・軽量な 1 カラム構成のファイルマネージャーです。
ターミナルの名作ファイルマネージャー **`nnn`** のような軽快な操作性をブラウザ GUI で実現し、**矢印キー中心の直感的なナビゲーション**でディレクトリを素早く移動・閲覧できます。

単一バイナリに必要な静的アセット（HTML/CSS/JS）がすべて内蔵されており、外部依存なしでミリ秒単位で高速起動します。

---

## 特徴

- ⌨️ **矢印キー主体 & Vim ライクな操作**:
  - `↓` / `↑` (または `j` / `k`): 項目の選択移動
  - `→` / `Enter` (または `l`): フォルダに入る、またはファイルを **[`edit`](file:///home/min/tools/edit)** で開く
  - `←` / `Backspace` (または `h`): 親ディレクトリへ戻る
  - `Home` / `End`: リストの先頭 / 末尾へジャンプ
- 🔍 **リアルタイム・インクリメンタル絞り込み**:
  - `/` キーを押すだけで即座に検索窓にフォーカスし、打った文字でリアルタイムに項目を絞り込み
  - `Esc` で検索解除
- 👁️ **隠しファイル切り替え**:
  - `.` キーでドットファイル（隠しファイル）の表示/非表示を瞬時にトグル
- 🔄 **3種の神器（webterm / edit / filer）シームレス連携**:
  - ファイルを選択して `→` または `Enter` または `e` を押すと、ポート 8081 の **Edit (Monaco Editor)** で即座に開く
  - `t` キーを押すと、カレントディレクトリを作業フォルダとしてポート 8080 の **Web Terminal (webterm)** を新規タブで開く
- 🧭 **パンくずナビゲーション & パスコピー**:
  - 上部にカレントパスの各階層がクリック可能なボタンとして表示され、任意の親階層へワンクリックでジャンプ可能
  - パスコピーボタンでカレントディレクトリのフルパスを即座にクリップボードへコピー
  - パンくずのダブルクリックで直接パス文字列の入力・移動も可能
- 📊 **見やすい1カラムリスト**:
  - フォルダ優先、名前順・サイズ順・更新日時順のソート対応
  - ファイル種別ごとのアイコン、サイズ、更新日時、パーミッションを表示
- 🖥️ **デスクトップランチャー & 常駐サービス対応**:
  - XFCE アプリケーションメニューやデスクトップアイコン（`filer.desktop`）からワンクリックで起動
  - `systemd` ユーザーサービスとして常駐可能（メモリ消費わずか ~2.7MB）
- 📱 **スマホ・別端末・リモートアクセス対応**:
  - Tailscale やローカルネットワーク経由で、スマートフォンやタブレットのブラウザからも安全に自宅PCのファイル閲覧・操作が可能
  - **スマホ向けタッチ最適化**: スマホ画面では画面下部に「親指操作用アクションバー（開く/新規/リネーム/移動/貼付/削除/端末）」および「親へ戻るボタン」が自動表示され、片手タッチだけで全ファイル操作が完結
  - Filerからクリックしたファイル編集（Edit連携）やターミナル起動（Webterm連携）もスマホ上でシームレスに連動

## 使い方

### 1. ターミナルから起動

```bash
# カレントディレクトリを開く (バックグラウンド起動 + ブラウザ自動オープン)
$ filer

# 特定のディレクトリを指定して開く
$ filer /home/min/tools

# 独立した単一ウィンドウ（Appモード）で開く
$ filer -app

# フォアグラウンドで実行（ログ確認）
$ filer -f

# ブラウザを自動で開かない (URLのみ出力)
$ filer -no-browser
```

### 2. ブラウザのお気に入り（ブックマーク）から開く常駐モード

ブラウザのブックマークバーに登録しておけば、ワンクリックでいつでもファイルマネージャーを開けます。

#### 常駐サービスの登録（推奨）
```bash
# 常駐サービスとして登録・即時起動 (systemd ユーザーサービス)
$ filer service install

# ステータス確認
$ filer service status

# 停止・アンインストール
$ filer service uninstall
```

※ `filer service install` で登録されるサービスは、全インターフェース（`0.0.0.0`）を待ち受ける設定で起動するため、同一PCローカルからもTailscale等の別端末からも利用可能です。

手動でバックグラウンド常駐させたい場合:
```bash
$ filer server -host 0.0.0.0
```

#### お気に入り（ブックマーク）URL
* **標準（ホームディレクトリで開く）**:
  👉 **`http://localhost:8082/`**
* **特定のフォルダで直接開く**:
  👉 **`http://localhost:8082/?cwd=/home/min/tools`**

---

### スマホや外出先から安全に使う (Tailscale 連携)

メッシュVPN **Tailscale** を導入することで、ルーターの面倒なポート開放を行わずに、スマホやタブレット、外出先から暗号化通信でセキュアにアクセスできます。

#### 1. セキュリティ設定 (UFW ファイアウォール)
ホストPC側で一度だけ実行しておきます：
```bash
sudo ufw allow in on tailscale0
```

#### 2. スマホ・別端末からのアクセス
スマホ等に Tailscale アプリを導入して接続（ON）した状態で、ブラウザから以下を開きます：

* **標準（ホームディレクトリで開く）**:
  👉 **`http://<Tailscale-IP>:8082/`**
* **特定のフォルダで直接開く**:
  👉 **`http://<Tailscale-IP>:8082/?cwd=/home/min/tools`**

Filer内からファイルを選択して「Edit」を押すと、同一ホストの **Edit (ポート 8081)** が開き、「Terminal (t)」を押すと **Webterm (ポート 8080)** がそのフォルダで開きます。スマホのホーム画面にショートカット（ブックマーク）を追加しておけば、外出先から自宅PCのファイル管理ステーションとして活用できます。

## キーボードショートカット一覧

| キー | 動作 |
| :--- | :--- |
| `↓` または `j` | 次の項目を選択 |
| `↑` または `k` | 前の項目を選択 |
| `→` または `Enter` または `l` | フォルダに入る / ファイルを `edit` で開く |
| `←` または `Backspace` または `h` | 親ディレクトリへ戻る |
| `Home` / `End` | リストの先頭 / 末尾へジャンプ |
| `/` | 絞り込み検索窓にフォーカス |
| `Esc` | 絞り込み検索解除 / パス入力解除 / モーダル閉じる / 切り取り解除 |
| `.` | 隠しファイルの表示 / 非表示トグル |
| `a` または `n` | 新規作成 (末尾に `/` を付けるとフォルダ作成) |
| `c` または `F2` または `R` | 名前の変更 (リネーム) |
| `d` または `Delete` | ゴミ箱へ移動 (削除) |
| `y` または `Ctrl+C` | コピー (Yank) |
| `x` または `Ctrl+X` | 切り取り (移動) - 対象行が半透明化 |
| `p` または `Ctrl+V` | 貼り付け (Paste) |
| `D` または `Ctrl+D` | 複製 (その場にコピー) |
| `t` | カレントフォルダでターミナル (`webterm`) を開く |
| `e` | 選択中のファイルをエディタ (`edit`) で開く |
| `r` | ディレクトリを再読み込み (更新) |
| `?` | キーボードショートカット一覧ヘルプの表示 / 非表示 |

## ディレクトリ構成

```text
├── main.go             # Goバックエンド (ファイル走査, サーバー, systemd連携)
├── go.mod              # Goモジュール定義
├── web/                # フロントエンド (バイナリに内蔵)
│   ├── index.html      # 1カラム UI 画面
│   ├── style.css       # スタイルシート (ダーク/ライトテーマ)
│   ├── app.js          # キーボードナビゲーション & 描画ロジック
│   └── favicon.svg     # アイコン
└── filer               # ビルド済みバイナリ (約 8MB)
```
